# Archaic structural variants shape modern human genomes
Here are the related pipelines and scripts used for the section `Archaic structural variants shape modern human genomes`. Detailed descriptions are provided in the manuscript.

1. [01.Detecting_pAID-vars](https://github.com/Asian-Pan-Genome/ArchaicIntrogression/tree/main/04.ArchaicStructuralVariants/01.Detecting_pAID-vars): this folder includes `graph construction`, `variants decomposition`, `genotyping pAID-vars in Neanderthal and Denisovan genomes`, etc.
2. [02.Expression](https://github.com/Asian-Pan-Genome/ArchaicIntrogression/tree/main/04.ArchaicStructuralVariants/02.Expression): this folder includes `RNA-SEQ alignment`, `gene expression normlization`, etc.
3. [03.Selection](https://github.com/Asian-Pan-Genome/ArchaicIntrogression/tree/main/04.ArchaicStructuralVariants/03.Selection): this folder includes `LD`, `EHH` analysis, etc.
4. [04.Other](https://github.com/Asian-Pan-Genome/ArchaicIntrogression/tree/main/04.ArchaicStructuralVariants/04.Other): this folder includes `protein structural modelling`, etc.
