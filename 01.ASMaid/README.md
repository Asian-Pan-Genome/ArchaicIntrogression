# ASMaid detects complete archaic introgression sequences from haplotype-resovled assemblies
This folder includes workflow and code scripts for the article section 1 (ASMaid detects complete archaic introgression sequences from haplotype-resovled assemblies). As for ASMaid pipeline, this folder contains the mapping and variant calling steps to work as pre-processing for the main pipeline. **The main ASMaid pipeline is available at** https://github.com/Asian-Pan-Genome/ASMaid. Simulation analysis and CN-based case analysis are also included in this folder.

## 01. Mapping and variant calling
This pipeline handles DNA alignment and variant discovery for both modern HGDP (Bergström et al., 2020, Science) samples and archaic hominins (Neanderthal Altai, Neanderthal Chagyrskaya, and Denisovan). Ten east African samples from HGDP were randomly selected for the introgression background control to mitigate ILS.  
To ensure high-quality variant calls across different types of sequencing data:
 - **Archaic DNA**: Processed via `blw aln` (optimized for damaged reads) and called via `GATK HaplotypeCaller`.
 - **Modern DNA**: Processed via `bwa mem` and called via `DeepVariant`.
 - **Joint Genotyping**: All samples are merged using `Glnexus` (DeepVariantWGS config).

## 02. Simulation analysis

This module is dedicated to generating simulation data, validating the performance of our proposed method (**ASMaid**) and comparing it against state-of-the-art introgression detection tools (**IBDmix** and **Sprime**). 

### Key Components:
- **Demographic Simulation**: Utilizing `msprime` to simulate complex Out-of-Africa evolutionary scenarios, including Neanderthal-to-Human gene flow (archaic introgression).
- **Cross-Tool Benchmarking**: A unified pipeline to process simulated data through multiple detection algorithms.
- **Statistical Evaluation**: Robust calculation of Precision, Recall, F1-score, and False Positive Rate (FPR) by comparing inferred tracts with the simulation ground truth.

## 03. CN-based case analysis (_MGAM_ gene)
This module focuses on the locus-specific analysis of the **MGAM gene**, a key candidate region showing significant copy number variations (CNV) and archaic introgression. We integrate depth profiling, protein domain annotation, and assembly-based synteny to characterize its evolutionary history.

### Key Components:
- **Copy Number Profiling**: Normalizing sequencing depth into bins across the introgression tract to visualize CNV landscapes (as shown in Figure 1d).
- **Structural Integrity Assessment**: Detecting assembly gaps (N-bases) and annotating protein domains by `hmmscan` to evaluate the functional impact of structural variants.
- **Synteny & Visualization**: Comparing assembly sequences via `minimap2` and visualizing structural rearrangements with `SVbyEye`.


## Dataset Summary

The `data/` directory contains standard BED files recording Neanderthal and Denisovan introgressed genomic segments for **13 overlapped individuals** present in both the 1000 Genomes Project (1KGP) and the Human Genome Structural Variation Consortium Phase 3 (HGSVCp3). All genomic coordinates are aligned and mapped to the **T2T-CHM13** reference genome.

### File Structure & Formats

The dataset comprises two main BED files categorized by resolution (diploid sample level vs. haploid assembly level):

1. **`IntrogressedSegments.Diploid.bed`**
   * **Scope**: Sample-level (diploid) introgressed segments detected across 5 state-of-the-art methods: **ASMaid**, **ArchaicSeeker2.0**, **hmmix**, **IBDmix**, and **Sprime**.
2. **`IntrogressedSegments.Haploid.bed`**
   * **Scope**: Haplotype/Assembly-level introgressed segments evaluated using 3 methods: **ASMaid**, **ArchaicSeeker2.0**, and **hmmix**.

Both files adopt a standardized **6-column BED format**:
* `Chrom`: Chromosome name (T2T-CHM13 coordinates).
* `Start`: segments start position.
* `End`: segments end position.
* `Sample/Assembly`: Sample identifier.
* `Archaic`: Inferred archaic source lineage (`Neanderthal` or `Denisovan`).
* `Method`: Name of the detection method used.

### Data Sources and Method-Specific Filtering Criteria

To ensure robust benchmarking and comparative analysis, introgressed tracts generated by external tools were retrieved from their official published repositories and processed strictly according to the quality control (QC) criteria recommended in their respective original publications:

| Method | Resolution Level | Original Source / Citation | Applied Filtering & Lineage Assignment Criteria |
| :--- | :--- | :--- | :--- |
| **ASMaid** | Diploid & Haploid | This study | Filtered for tracts with posterior probability $> 0.9$. |
| **ArchaicSeeker2.0** | Diploid & Haploid | [GitHub](https://github.com/Shuhua-Group/ArchaicSeeker2.0/tree/master/IntrogressedSeg/KGP) <br> *(Yuan et al., 2021, Nat Commun)* | Classified based on reported labels: tracts labeled `Altai` and `Denisova_Altai` were assigned as **Neanderthal**; tracts labeled `Denisova` and `Denisova_Altai` were assigned as **Denisovan**. |
| **hmmix** | Diploid & Haploid | [Zenodo (14136628)](https://zenodo.org/records/14136628) <br> *(Skov et al., 2018, PLOS Genet)* | Filtered for posterior probability $\ge 0.8$. Lineage assignments: `Neanderthal` and `Both` labels $\rightarrow$ **Neanderthal**; `Denisova` and `Both` labels $\rightarrow$ **Denisovan**. |
| **IBDmix** | Diploid | [Zenodo (14552025)](https://zenodo.org/records/14552025) <br> *(Liang et al., 2025, Genome Biol)* | Filtered for LOD score $> 4$ and segment length $> 50$ kbp. |
| **Sprime** | Diploid | [Mendeley Data](https://data.mendeley.com/datasets/y7hyt83vxr/1) <br> *(Browning et al., 2018, Cell)* | Disambiguated by match rates to archaic reference genomes: <br> • **Neanderthal**: Match rate $> 0.6$ to Altai Neanderthal and $< 0.4$ to Altai Denisovan. <br> • **Denisovan**: Match rate $> 0.4$ to Altai Denisovan and $< 0.3$ to Altai Neanderthal. |
